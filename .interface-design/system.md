# CLUB 40 — админка: дизайн-система

Рабочий инструмент администратора: нейтральный, плотный, светлый (тёмной темы
нет — dark:-варианты в коде не работают и новые не добавляем). Единственный
громкий элемент — фирменный заголовок страницы в шапке.

## Айдентика (осознанный кастом — не трогать)

- Заголовок страницы в AdminShell: Helvetica Neue **900 italic uppercase**,
  `text-2xl` — фирменный голос админки.
- Кнопка Kate (AI): `ai-gradient` — единственный градиент в приложении.
- Жёлтого бренда клиентского приложения в админке нет намеренно: это
  нейтральный рабочий инструмент, а не витрина.

## Цвет

Токены shadcn (light). Семантическая палитра статусов — tailwind-оттенки,
строго по значению:

| Значение                                       | Цвета                                               |
| ---------------------------------------------- | --------------------------------------------------- |
| положительное / активный / приход              | `emerald` (chip: `bg-emerald-100 text-emerald-700`) |
| отрицательное / расход / отменено              | `rose` (chip: `bg-rose-100 text-rose-700`)          |
| нейтрально-информационное / «Приложение» / ПЧК | `blue` (chip: `bg-blue-100 text-blue-700`)          |
| предупреждение / внимание                      | `amber` / `orange`                                  |
| ошибка / удаление                              | токен `destructive`, не красный литерал             |

Оттенок фона чипов — всегда `-100` (не `-50`). Прочие цвета — только токены
(`muted`, `muted-foreground`, `border`, …).

## Чипы и бейджи

Единая геометрия: **пилюля** `rounded-full px-2 py-0.5 text-xs font-medium`.

- `<Badge>` (ui/badge) — базовые случаи, геометрия уже пилюльная.
- `ClubStatusBadge` (ЧК/ПЧК/БЧК) — с цветным бордером, это его отличие.
- `MembershipStatusBadge` / `AutoRenewBadge`, `SourceBadge` — без бордера.
- Новые статусы делать компонентом рядом с существующими, не inline-строкой.

## Контролы

- Кнопки — только `<Button>`; в тулбарах `size="sm"` (h-8), формы — default.
  Raw `<button>` допустим только для текстовых ссылок-действий в таблицах
  (имя клиента) и ячеек календаря расписания.
- Поля — `<Input>` (h-9). **Поиск в слоте фильтров AdminShell**: `h-8 pl-8`,
  иконка `Search` `left-2.5 h-4 w-4`. **Панель фильтров в теле страницы**
  (Клиенты): контролы `h-9`, поиск `pl-9`, иконка `left-3`.
- Селекты в слоте фильтров — `h-8`, в панели — `h-9`.

## Таблицы

- Обёртка: `rounded-lg border bg-background`, внутри `<Table>` из ui.
- Заголовки колонок не переносятся: `whitespace-nowrap` зашит в TableHead.
- Состояние загрузки: ячейка на всю ширину, `py-8 text-center
text-muted-foreground` + `<Loader2 class="mx-auto h-5 w-5 animate-spin">`.
- Пустое состояние: `py-8 text-center text-sm text-muted-foreground`,
  текст различает «ничего нет» и «ничего не найдено» (по активному фильтру).
- Числа/деньги в колонках — `tabular-nums` при добавлении новых колонок.
- Пагинация — `<DataPagination {...pg} />` сразу под таблицей.

## Страницы

- Табличные разделы — **на всю ширину** зоны справа от бокового меню:
  контейнер `space-y-3` без max-w (main уже даёт p-6). Расписание — тоже на
  всю ширину. Исключения: настройки клуба `max-w-2xl` и push-triggers
  `max-w-3xl` (это формы).
- **Поиск и фильтры — только на плашке `TableToolbar`**
  (`src/components/table-toolbar.tsx`) первой в контейнере, сразу над
  таблицей. Всегда одна строка: `ToolbarSearch` ограничен `max-w-96`
  (~под самый длинный placeholder с запасом, на весь экран не тянется),
  селекты фиксированной ширины h-8, без лейблов над контролами; диапазоны
  дат — компактные кнопки dd.MM.yy. Слота filters в AdminShell больше нет.
- Все разделы, включая «Сотрудников», используют AdminShell (title + actions).
- Страница без выбранной студии: карточка `rounded-lg border bg-background
p-8 text-center text-sm text-muted-foreground` «Сначала выберите студию».
- Диалоги: `max-w-lg` по умолчанию, длинные формы — `max-w-xl/2xl` +
  `max-h-[90vh] overflow-y-auto`.

## Пространство и глубина

База 4px. Глубина — границы (`border`) + светлые поверхности, теней почти
нет. Радиусы: контролы `rounded-md`, карточки/обёртки таблиц `rounded-lg`,
чипы `rounded-full`.
