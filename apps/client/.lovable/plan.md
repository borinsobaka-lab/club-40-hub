## Что меняем на странице «Абонементы»

### 1. Структура карточки (по референсу)

Каждая карточка превращается в единый блок с двумя зонами:

**Верхняя зона (на фоновой картинке `cover_url`)**
- Заголовок абонемента
- Крупная цена + подпись срока («в месяц», «за N месяцев», «за год» — выводим из `duration_days`)
- Короткое описание (`description`)
- Кнопка «Выбрать» во всю ширину

**Нижняя зона (на обычном фоне карточки)**
- Подзаголовок «Преимущества»
- Список преимуществ с зелёными галочками (как сейчас в детальном просмотре): `visits_count`/«Безлимит», срок, плюс пункты из `benefits[]`

Фон верхней зоны: `storage.getPublicUrl('memberships-media', cover_url)`. Если `cover_url` пуст — используем нейтральный фон (текущий цветной акцент по индексу). Поверх картинки кладём лёгкий градиент-затемнение, чтобы текст оставался читаемым (белый текст на верхней зоне).

```text
┌─────────────────────────────┐
│ [bg: cover_url]             │
│  Название                   │
│                             │
│  2 400 ₾                    │
│  за месяц                   │
│                             │
│  Короткое описание…         │
│                             │
│  [   Выбрать   ]            │
├─────────────────────────────┤
│ ПРЕИМУЩЕСТВА                │
│ ✓ Безлимит посещений        │
│ ✓ Срок 30 дней              │
│ ✓ Заморозка до 7 дней       │
│ ✓ Гостевой визит            │
└─────────────────────────────┘
```

### 2. Горизонтальный скролл

Вместо вертикального списка — горизонтальный скролл-ряд карточек (snap-x, шаг по карточке, скрытый скроллбар). Карточка фиксированной ширины ~85% вьюпорта, чтобы был виден край следующей. Разделение на табы «Безлимитные / Пакеты тренировок» сохраняем — внутри каждого таба свой горизонтальный ряд.

### 3. Поведение клика

Тап по карточке или по кнопке «Выбрать» открывает текущий `MembershipDrawer` без изменений логики покупки. Drawer оставляем — он нужен для подтверждения, заморозки активного и т.д.

### 4. Источник картинки

- Поле `memberships.cover_url` уже существует в БД (путь в бакете `memberships-media`).
- Получаем публичный URL: `supabase.storage.from('memberships-media').getPublicUrl(cover_url).data.publicUrl`.
- Добавляем `cover_url` в `select` и в тип `Membership`.
- SVG отдаётся как файл напрямую — никакой спец-обработки, просто `<img src>` / `background-image`.

### Технические детали

- Меняется только `src/routes/memberships.tsx`:
  - расширяем `select` и тип `Membership` полем `cover_url`;
  - добавляем хелпер `coverUrl(m)` через `supabase.storage`;
  - переписываем разметку списка: контейнер `flex overflow-x-auto snap-x snap-mandatory`, карточки `w-[85%] shrink-0 snap-start`;
  - новая верстка карточки (верх с `background-image` + затемнение, низ со списком преимуществ и галочками `CheckCircle` из `@solar-icons/react`);
  - формат подписи срока: 30 дн → «в месяц», 90 → «за 3 месяца», 180 → «за 6 месяцев», 365 → «в год», иначе — «на N дней».
- Drawer и логика покупки — без изменений.
- Никаких миграций БД не нужно (поле уже есть, бакет публичный).
