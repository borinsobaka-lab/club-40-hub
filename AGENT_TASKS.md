# Задача 2. Включить фирменные письма авторизации (20 минут)

Сейчас письма для входа уходят с адреса Supabase по их шаблонам. Нужно, чтобы
они уходили с **noreply@base40.fit** и были **разными**: сотрудникам админки —
ссылка авто-входа, клиентам приложения — 4-значный код. Код для этого написан,
осталось соединить сервисы.

**Порядок шагов обязателен.** Если включить хук (шаг 4) раньше, чем заданы
переменные и сделан рестарт (шаг 3), письма перестанут уходить совсем.

### Шаг 1. Ключ Resend

1. Resend → **Domains**: домен `base40.fit` должен быть в статусе
   **Verified**. Если нет — Resend покажет DNS-записи (SPF, DKIM); добавь их
   в Cloudflare DNS для `base40.fit` (Proxy = DNS only) и дождись верификации.
   Без этого письма не дойдут.
2. Resend → **API Keys** → **Create API Key**, права **Sending access**.
   Скопируй ключ (начинается с `re_`) — он показывается один раз.

### Шаг 2. Секрет хука в Supabase

1. Supabase Dashboard → **Authentication** → **Hooks**.
2. Найди **Send Email Hook** → тип **HTTPS**.
3. URL: `https://admin.base40.fit/api/auth-email`
4. Скопируй **сгенерированный секрет** (вида `v1,whsec_...`).
5. **НЕ включай хук (не ставь Enabled) — сначала шаг 3.**

### Шаг 3. Переменные в Coolify и рестарт

1. https://coolify.base40.fit → проект **club40** → приложение
   **club40-admin** → **Environment Variables**.
2. Добавь две переменные. Галочку **Build Variable НЕ ставить** (это
   runtime-секреты, в клиентский код они попадать не должны):

   | Имя                      | Значение                                   |
   | ------------------------ | ------------------------------------------ |
   | `SEND_EMAIL_HOOK_SECRET` | секрет из шага 2 (целиком, вместе с `v1,`) |
   | `RESEND_API_KEY`         | ключ Resend из шага 1                      |

3. Сохрани и нажми **Restart** (именно рестарт, редеплой не нужен).
4. Проверка: подожди ~30 секунд. Прежний ответ обработчика был
   «hook not configured»; теперь на запрос без подписи он должен отвечать
   «invalid signature». Если у тебя нет удобного способа послать POST —
   пропусти проверку, её покроет шаг 6.

### Шаг 4. Включить хук

Вернись в Supabase → Authentication → Hooks → Send Email Hook → **Enable**
и сохрани.

### Шаг 5. Длина кода — 4 цифры

Supabase → **Authentication** → **Sign In / Up** → провайдер **Email**:

- **Email OTP Length**: поставь **4** (по умолчанию 6 — клиентское приложение
  ждёт ровно 4 цифры, иначе вход не сработает).
- **Email OTP Expiration**: 3600 секунд.

Сохрани.

### Шаг 6. Проверка писем

1. **Клиент**: открой https://app.base40.fit → введи почту (любую свою,
   не рабочую) → «Получить код». Должно прийти письмо от
   `CLUB 40 <noreply@base40.fit>` с **4 цифрами и без ссылок**. Введи код —
   вход должен произойти.
2. **Сотрудник**: открой https://admin.base40.fit → войди почтой владельца и
   паролем. Должно прийти письмо **со ссылкой** «Войти в админ-панель»
   (кода в нём быть не должно). Переход по ссылке = вход.
3. Проверь, что письма не попали в спам.

Если письма не приходят: Coolify → club40-admin → **Logs**, ищи строки
`[auth-email]` — там будет причина. Аварийный откат: выключить хук в
Supabase (вернутся стандартные письма Supabase).

### Шаг 7. Лимиты

Supabase → **Authentication** → **Rate Limits**: лимит на отправку писем
подними до разумного (например, **100 в час**) — отправка теперь идёт через
Resend, а не через общий SMTP Supabase.
