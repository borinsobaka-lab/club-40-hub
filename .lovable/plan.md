## Цель
Вернуть выбор типа тренировки (Силовая / Кардио / Гибрид / Восстановление) в карточке тренировки и показывать его цветной иконкой в таблице. Расписание и мобильное приложение уже умеют читать `workouts.type` — нужно только наполнять это поле из админки.

## Что уже есть (не трогаем)
- В БД колонка `public.workouts.type` (`strength | cardio | hybrid | recovery | null`) уже создана — миграция не нужна.
- Палитра типов и хелперы лежат в `src/lib/workout-types.ts` (`DAY_TYPES`, `dayTypeLabel`, `dayTypeColor`).
- `schedule.tsx` уже подтягивает `workouts.type`, красит занятия и фильтрует по типу.
- Мобильное клиентское приложение — отдельный проект; так как поле в БД уже отдается, ему достаточно того, что админка начнёт его заполнять. Здесь ничего не правим.

## Что меняем (только `src/routes/_authenticated/workouts.tsx`)

### 1. Тип `Workout`
Добавляем поле:
```ts
type: DayType | null;
```
Импорт из `@/lib/workout-types`.

### 2. Колонка «Тип» в таблице
Между «Название» и «Описание» добавляем `TableHead` «Тип» (ширина ~140px) и ячейку с цветным бейджем:
- кружок-точка цвета `dayTypeColor(w.type).dot` + подпись `dayTypeLabel(w.type)`;
- если `type === null` — выводим «—» серым.
`colSpan` пустых/loading-строк увеличиваем с 5 до 6.

### 3. Диалог создания/редактирования
В `WorkoutDialog`:
- Локальный стейт `const [type, setType] = useState<DayType | "">("")`.
- В `useEffect` инициализации — `setType(workout?.type ?? "")`.
- Новое поле перед «Вместимостью»: `Select` (shadcn) с пунктами из `DAY_TYPES` + пункт «Не указан» (значение `__none__`, сохраняем как `null`). В каждом пункте — цветная точка слева.
- В `payload` добавляем `type: type === "" ? null : type`.

### 4. Поиск
Расширяем фильтр `filteredWorkouts`: дополнительно матчим по `dayTypeLabel(w.type)`, чтобы можно было искать «кардио» текстом.

## Технические детали
- Никаких изменений в схеме БД, RLS, миграциях.
- Никаких правок в `schedule.tsx` и мобильном приложении — они уже потребляют `type` корректно.
- Цвета берём строго из `DAY_TYPE_COLORS`, чтобы расписание и таблица тренировок выглядели одинаково.

## Проверка после внедрения
1. Создать тренировку с типом «Кардио» → в таблице появляется синяя точка + «Кардио».
2. Отредактировать существующую → тип сохраняется.
3. Открыть расписание → занятие с этой тренировкой красится в соответствующий цвет (уже работает).
